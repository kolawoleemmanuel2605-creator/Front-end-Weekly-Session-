Introduction

I started learning web development in 2026. I have always had an interest in development, especially game development, but as I grew older, I gradually became more interested in web development. Building websites and applications is something I have always wanted to do, so I decided to start my journey with web development.

When I started, I thought I would be able to learn it quickly and that it would be easy. I soon discovered that it was not as simple as I expected. The journey has been rough at times, with slow progress and moments when my motivation was low. However, I have decided to keep trying because I know that giving up will not help me improve.

HTML was not too difficult for me at first. Things became more challenging when I started learning CSS. There are many concepts to understand, and sometimes I feel stuck. However, I have realized that struggling is part of learning something new. With determination, commitment, consistent practice, and by God's grace, I believe I will continue to improve.

What I Have Learned

So far, I have learned several concepts in HTML, including:

  1. Semantic HTML and webpage structure
  2. Images
  3. Links
  4. Lists
  5. Tables
  6. Headings and Paragraphs
  7. Basic webpage structure

Learning these concepts has helped me understand how webpages are organized and how different elements work together. I have also learned that understanding the basics and practicing regularly are important parts of becoming a better web developer.

I still have a lot to learn, but I am gradually becoming more comfortable with web development. My goal is to continue practicing, build real projects, improve my problem-solving skills, and eventually become skilled enough to create useful websites and applications on my own.

About

My name is Kolawole Emmanuel. I am a 100-level student at the University of Lagos (UNILAG), studying Data Science. I am interested in technology, web development, and learning how things work. I am currently developing my programming skills and working toward becoming a skilled and confident developer.
